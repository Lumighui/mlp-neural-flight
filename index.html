02 / THE ROUTE

七个计算站点

每张卡片都是同一组数据的一次变换。数字变多并不神秘， 关键是看清“输入 × 权重 + 偏置”之后发生了什么。

01

INPUT

装载两个特征

x = [0.80, 0.60]

专注度与截止时间紧迫度进入网络，数值本身还没有任何“判断”。

02

WEIGHTED SUM

乘权重，再相加

zᵢ = Σ xⱼ · wᵢⱼ

每个隐藏神经元用自己的权重组合两个特征，看重它们的角度并不相同。

03

BIAS

加上偏置

zᵢ = Σ xⱼ · wᵢⱼ + bᵢ

偏置像每个神经元的出发点，使它在输入全为零时也可能保留不同倾向。

04

RELU

剪掉负信号

aᵢ = max(0, zᵢ)

ReLU 让负值归零、正值原样通过。本例的 h₁ 就在这里被关闭。

05

HIDDEN → OUTPUT

汇总有效信号

0 × .55 + .60 × .65 + 1.08 × .85

输出层不会平均三票，而是为每个隐藏神经元分配新的权重。

06

LOGIT

得到原始得分

0.390 + 0.918 − 0.530 = 0.778

此时的 0.778 可以继续增大或变小，还不能直接解释成概率。

07

SIGMOID

压缩成概率

σ(0.778) ≈ 68.5%

Sigmoid 把任意实数压到 0 与 1 之间，输出因此可被当作二分类概率。

03 / MODEL CARD

这不是黑箱，
只是一串连续变换。

本例展示的是训练完成后的一次前向传播。 权重和偏置已经给定，因此每一步都可以手算。真实网络通过反向传播与梯度下降， 反复调整这些参数来减少误差。

TRAINING ≠ INFERENCE

本页不更新参数；它回答的是“现有模型收到这条输入后，会输出什么”。
